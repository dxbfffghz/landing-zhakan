# landing-zhakan

**Topic:** Photographer portfolio — Akerke Zhakan
**Live link:** https://<dxbfffghz>.github.io/landing-zhakan/

## What was done

- Landing page built with pure HTML5 + CSS3. No templates, no builders, no frameworks.
- Semantic tags: `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `address`, `footer`.
- 6 blocks: Hero, About, Portfolio, Services, Contact (with form), Footer.
- Contact form with fields Name, Email, Message — each has a `<label>` and `required`.
- All images have descriptive `alt` attributes.
- Heading hierarchy: `h1` → `h2` → `h3`.
- `<head>` contains `title`, `meta description`, `meta viewport`, favicon (SVG).
- Responsive layout checked at 375 px (mobile) and 1280 px (desktop).
- Accessibility: `aria-label` on nav and logo, `loading="lazy"` on images, `autocomplete` on inputs.

## Tech

HTML5, CSS3 (CSS Grid, Flexbox, custom properties). No JavaScript frameworks.
